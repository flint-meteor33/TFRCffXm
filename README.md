# 项目简介

## 核心功能
- 基于YOLOv8的汽车外观部件实例分割检测系统
- 支持16类汽车部件检测，包括boot、car、door、front_bumper等
- 提供完整源码、标注数据集、训练好的模型及训练结果
- 支持多种输入源：单张图片、图片文件夹、视频文件、本地摄像头
- 实时显示目标位置、目标总数、置信度等信息
- 支持批量检测并查看所有检测结果
- 可自定义置信度和IOU阈值
- 支持选择检测模型
- 可选择显示标签和原图

## 适用场景
- 汽车外观检测与识别
- 汽车零部件质量控制
- 汽车图像分析研究
- 自动驾驶视觉系统开发
- 汽车维修辅助识别

## 技术特点
- 使用Pycharm+Anaconda或VSCode+Anaconda开发环境
- 依赖python3.9、opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 包含完整的UI界面源文件和图标
- 提供1600张标注数据集
- 已训练好模型，配置环境后可直接使用
- 支持检测结果保存功能
